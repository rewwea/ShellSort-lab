### 5. Анализ корректности

Алгоритм корректно сортирует:
	•	уже отсортированные данные
	•	обратный порядок
	•	случайные данные
	•	почти отсортированные

Проверка корректности:

sorted(arr) == shell_sort(arr.copy())[0]

— проходит во всех случаях.

⸻

### 6. Устойчивость (stable)

Был использован массив пар вида (ключ, индекс):
	•	Порядок одинаковых ключей не сохраняется
	•	Поэтому сортировка Шелла не является устойчивой

⸻

### 7. Адаптивность
	•	На отсортированных данных алгоритм работает заметно быстрее
	•	На почти отсортированных — тоже показывает ускорение
	•	На обратных данных — время хуже всего

Вывод: сортировка Шелла частично адаптивна.

⸻

### 8. Асимптотическая сложность

Случай	Оценка
Лучший	O(n log n)
Средний	O(n^1.25 … n^1.5) — зависит от последовательности шагов
Худший	O(n²)
